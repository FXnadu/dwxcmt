# dwxComment 数据库设计文档 v3.1

> 版本：v3.1 ｜ 本文档为《02-系统架构设计》的数据库细化
> 引擎：SQLite 3（`modernc.org/sqlite` 纯 Go 驱动）
> 基于《技术设计说明书 v2》拆分，已纳入 settings/likes/migration_versions 表、置顶字段；v3 移除图片字段；v3.1 同步至迁移 010（is_admin / 多管理员 / 2FA / pin_time）

---

## 1. 数据库概览

- 单文件数据库：`comment.db`（运行时自动创建）
- 无独立数据库进程，无网络交互
- 首次启动自动建表，后续按 `migration_versions` 表版本号自动迁移
- 字符编码：UTF-8

### 表清单
| 表名 | 用途 | 状态 |
|------|------|----------|
| `comments` | 评论与回复 | 含 `is_pinned`，`is_audited` 默认 0；v3 移除 `image_url`；v3.1 补 `is_admin`、`pin_time` |
| `admins` | 管理员 | 含 OAuth 绑定、邮箱、2FA、多管理员权限字段（v3.1） |
| `settings` | 系统配置 | **v2 新增**，v3.1 补 `siteUrl`、`pagerType` 等键 |
| `likes` | 点赞去重记录 | **v2 新增**，1 分钟窗口清理 |
| `rate_limits` | 限流计数 | 每日清理 30 天 |
| `migration_versions` | 迁移版本追踪 | **v2 新增** |

## 2. 表结构设计

### 2.1 评论表 `comments`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 评论唯一 ID |
| `page_id` | TEXT | NOT NULL, INDEX | 所属文章标识，如 `/post/xxx.html` |
| `site` | TEXT | DEFAULT '' | 多站点标识（可选） |
| `nick` | TEXT | NOT NULL | 评论者昵称 |
| `email` | TEXT | DEFAULT '' | 邮箱，用于回复通知，**不公开** |
| `link` | TEXT | DEFAULT '' | 个人网站链接 |
| `content` | TEXT | NOT NULL | 评论正文（可包含 Markdown 图片 URL） |
| `parent_id` | INTEGER | DEFAULT 0 | 父评论 ID，0 为顶级评论 |
| `root_id` | INTEGER | DEFAULT 0 | 根评论 ID，便于按层级展示 |
| `like_count` | INTEGER | DEFAULT 0 | 点赞数 |
| `is_audited` | INTEGER | DEFAULT 0 | **[v2 变更]** 审核状态：1 通过，0 待审，-1 垃圾。默认 0（全量待审） |
| `is_pinned` | INTEGER | DEFAULT 0 | **[v2 新增]** 是否置顶：1 置顶，0 普通 |
| `pin_time` | INTEGER | DEFAULT 0 | **[v3.1 新增]** 置顶时间戳（秒）；置顶区按它倒序（后置顶的排最上），取消置顶清空为 0 |
| `is_admin` | INTEGER | DEFAULT 0 | **[v2.4 新增]** 站长回复标识：1 = 站长/管理员身份（前台展示「站长」徽章），0 = 普通用户 |
| `ip` | TEXT | DEFAULT '' | 评论者 IP |
| `user_agent` | TEXT | DEFAULT '' | UA 信息 |
| `create_time` | INTEGER | NOT NULL, INDEX | 创建时间戳（秒） |
| `update_time` | INTEGER | NOT NULL | 更新时间戳 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS comments (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    page_id     TEXT    NOT NULL,
    site        TEXT    DEFAULT '',
    nick        TEXT    NOT NULL,
    email       TEXT    DEFAULT '',
    link        TEXT    DEFAULT '',
    content     TEXT    NOT NULL,
    parent_id   INTEGER DEFAULT 0,
    root_id     INTEGER DEFAULT 0,
    like_count  INTEGER DEFAULT 0,
    is_audited  INTEGER DEFAULT 0,
    is_pinned   INTEGER DEFAULT 0,
    pin_time    INTEGER DEFAULT 0,
    is_admin    INTEGER DEFAULT 0,
    ip          TEXT    DEFAULT '',
    user_agent  TEXT    DEFAULT '',
    create_time INTEGER NOT NULL,
    update_time INTEGER NOT NULL
);
```
> 注：`pin_time`、`is_admin` 由迁移 010 / 005 以 `ALTER TABLE ADD COLUMN` 方式追加，建库路径为「001 初始建表 → 逐级迁移」。

### 2.2 管理员表 `admins`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 管理员 ID |
| `username` | TEXT | NOT NULL, UNIQUE | 登录用户名 |
| `password_hash` | TEXT | NOT NULL | bcrypt 哈希密码（cost ≥ 10） |
| `email` | TEXT | DEFAULT '' | **[v2.4 新增]** 绑定邮箱（登录/2FA 用），唯一部分索引（空串不参与） |
| `twofa_enabled` | INTEGER | DEFAULT 0 | **[v3.1 新增]** 是否开启邮箱验证码两步验证（1=开启；开启前置条件为已绑定邮箱） |
| `can_delete` | INTEGER | DEFAULT 0 | **[v3.1 新增]** 删除评论权限（1=是）；站长默认持有，其余账号由站长授予 |
| `is_approved` | INTEGER | DEFAULT 1 | **[v3.1 新增]** 是否已通过站长审批（1=是，未通过不可登录）；首个注册账号默认通过 |
| `is_disabled` | INTEGER | DEFAULT 0 | **[v3.1 新增]** 账号是否被禁用（1=禁用，无法登录，需站长手动启用） |
| `is_owner` | INTEGER | DEFAULT 0 | **[v3.1 新增]** 是否为站长（首个注册账号，1=是），可审批新账号、授予/收回权限 |
| `qq_openid` | TEXT | DEFAULT '' | QQ 互联 openid，个人中心绑定 QQ 用 |
| `qq_name` | TEXT | DEFAULT '' | **[v2.1 新增]** QQ 昵称 |
| `github_openid` | TEXT | DEFAULT '' | **[v2.1 新增]** GitHub 绑定 openid |
| `github_name` | TEXT | DEFAULT '' | **[v2.1 新增]** GitHub 昵称 |
| `create_time` | INTEGER | NOT NULL | 创建时间 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS admins (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    username      TEXT    NOT NULL UNIQUE,
    password_hash TEXT    NOT NULL,
    qq_openid     TEXT    DEFAULT '',
    create_time   INTEGER NOT NULL
);
-- 后续迁移追加（002）github_openid/github_name/qq_name
-- （004）email + 唯一部分索引 idx_admins_email
-- （007）twofa_enabled
-- （008）can_delete / is_approved / is_owner（存量最早账号自动成为站长）
-- （009）is_disabled
```

> 多管理员模型：首个注册账号自动成为站长（`is_owner=1`，`is_approved=1`，`can_delete=1`）；后续注册账号默认待审批（`is_approved=0`），站长在后台审批通过后方可登录。注册入口不再关闭。

### 2.3 系统配置表 `settings`（v2 新增）

替代 v1 中缺失的持久化配置存储。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 记录 ID |
| `site` | TEXT | NOT NULL, DEFAULT 'default' | 站点标识，支持按站点隔离配置 |
| `key` | TEXT | NOT NULL | 配置键 |
| `value` | TEXT | DEFAULT '' | 配置值（JSON 字符串或纯文本） |
| `update_time` | INTEGER | NOT NULL | 最后修改时间 |
| UNIQUE(`site`, `key`) | | | 站点 + 键联合唯一 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS settings (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    site        TEXT    NOT NULL DEFAULT 'default',
    key         TEXT    NOT NULL,
    value       TEXT    DEFAULT '',
    update_time INTEGER NOT NULL,
    UNIQUE (site, key)
);
```

**预定义配置键**：

| key | 说明 | 示例值 |
|-----|------|--------|
| `siteName` | 站点名称 | `我的博客` |
| `siteUrl` | 站点地址 | `https://blog.example.com` |
| `noticeEmail` | 管理员通知邮箱 | `admin@example.com` |
| `auditMode` | 审核模式，固定 `"all"`（不可改） | `"all"` |
| `notifyNewComment` | 新评论待审通知管理员 | `"1"` / `"0"` |
| `notifyReply` | 回复通知被回复者 | `"1"` / `"0"` |
| `adminBadge` | 站长徽章文案（默认「站长」，≤10 字） | `站长` |
| `adminAvatar` | 站长头像 URL（默认空 = 字母头像） | `https://example.com/me.png` |
| `adminNick` | 站长昵称（站长回复显示，默认「站长」） | `站长` |
| `pagerType` | 评论区翻页方式：`more`（加载更多，默认）/ `pages`（页码分页） | `more` |

### 2.4 点赞记录表 `likes`（v2 新增）

持久化点赞去重，解决 v1 中无表定义的问题。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 记录 ID |
| `comment_id` | INTEGER | NOT NULL | 被点赞评论 ID |
| `ip` | TEXT | NOT NULL | 点赞者 IP |
| `create_time` | INTEGER | NOT NULL | 点赞时间戳（秒） |
| UNIQUE(`comment_id`, `ip`) | | | 同 IP 同评论去重 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS likes (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    comment_id  INTEGER NOT NULL,
    ip          TEXT    NOT NULL,
    create_time INTEGER NOT NULL,
    UNIQUE (comment_id, ip)
);
```

> 定时清理：`CleanupStaleData` 每小时删除 `create_time` 超过 **1 分钟**（`LikeWindow`）的去重记录；`like_count` 计数永久保留、绝不清零，窗口外同一 IP 可再次点赞。

### 2.5 限流记录表 `rate_limits`

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | 记录 ID |
| `identifier` | TEXT | NOT NULL | IP 地址或用户标识 |
| `date` | TEXT | NOT NULL | 日期（YYYY-MM-DD） |
| `count` | INTEGER | DEFAULT 0 | 当日已提交评论数 |
| UNIQUE(`identifier`, `date`) | | | 联合唯一索引 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS rate_limits (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    identifier TEXT    NOT NULL,
    date       TEXT    NOT NULL,
    count      INTEGER DEFAULT 0,
    UNIQUE (identifier, date)
);
```

> 定时清理：每日凌晨清理超过 30 天的记录，防无限增长。

### 2.6 数据库迁移版本表 `migration_versions`（v2 新增）

| 字段名 | 类型 | 约束 | 说明 |

**DDL**：
```sql
CREATE TABLE IF NOT EXISTS migration_versions (

```

## 3. 索引设计

| 索引名 | 字段 | 用途 | 变更 |
|--------|------|------|---------|
| `idx_page_site_time` | `(page_id, site, is_audited, is_pinned, create_time DESC)` | 主查询：审核筛选 + 置顶排序 | 复合索引加 is_audited + is_pinned |
| `idx_page_site_pin` | `(page_id, site, is_audited, is_pinned, pin_time DESC)` | **[v3.1 新增]** 置顶区按置顶时间倒序 | 迁移 010 |
| `idx_root_id` | `root_id` | 按根评论聚合查询 | — |
| `idx_audited` | `is_audited` | 筛选待审核评论 | — |
| `idx_parent_id` | `parent_id` | 查询子回复 | — |
| `idx_email` | `email` | 回复通知按邮箱反查 | v2 新增 |
| `idx_site_single` | `site` | 多站点独立查询 | v2 新增 |
| `idx_site_audited_time` | `(site, is_audited, create_time DESC)` | **[v3.1 新增]** 最近评论/站点筛选 | 迁移 006 |
| `idx_audited_time` | `(is_audited, create_time DESC)` | **[v3.1 新增]** 待审列表 | 迁移 006 |
| `idx_ip_page_time` | `(ip, page_id, create_time)` | **[v3.1 新增]** 提交评论重复检测 | 迁移 006 |
| `idx_likes_time` | `likes(create_time)` | **[v3.1 新增]** 点赞记录定时清理 | 迁移 006 |
| `idx_admins_email` | `admins(email) WHERE email <> ''` | **[v3.1 新增]** 邮箱登录/2FA 反查（唯一部分索引） | 迁移 004 |

**DDL**：
```sql
CREATE INDEX IF NOT EXISTS idx_page_site_time ON comments (page_id, site, is_audited, is_pinned, create_time DESC);
CREATE INDEX IF NOT EXISTS idx_page_site_pin  ON comments (page_id, site, is_audited, is_pinned, pin_time DESC);
CREATE INDEX IF NOT EXISTS idx_root_id        ON comments (root_id);
CREATE INDEX IF NOT EXISTS idx_audited         ON comments (is_audited);
CREATE INDEX IF NOT EXISTS idx_parent_id      ON comments (parent_id);
CREATE INDEX IF NOT EXISTS idx_email           ON comments (email);
CREATE INDEX IF NOT EXISTS idx_site_single    ON comments (site);
CREATE INDEX IF NOT EXISTS idx_site_audited_time ON comments (site, is_audited, create_time DESC);
CREATE INDEX IF NOT EXISTS idx_audited_time    ON comments (is_audited, create_time DESC);
CREATE INDEX IF NOT EXISTS idx_ip_page_time    ON comments (ip, page_id, create_time);
CREATE INDEX IF NOT EXISTS idx_likes_time      ON likes (create_time);
CREATE UNIQUE INDEX IF NOT EXISTS idx_admins_email ON admins (email) WHERE email <> '';
```

> `likes` / `rate_limits` 通过 `UNIQUE` 约束自动生成索引，无需额外创建。

## 4. SQLite 优化配置

首次连接时执行（由 `model/db.go` 统一设置）：

```sql
PRAGMA journal_mode = WAL;      -- 写前日志，读写并发不互斥
PRAGMA cache_size = -4096;      -- 4MB 内存页缓存
PRAGMA synchronous = NORMAL;    -- 兼顾安全与性能（WAL 模式下安全）
PRAGMA temp_store = MEMORY;     -- 临时表/排序放内存
PRAGMA mmap_size = 268435456;   -- 256MB 内存映射，加速读
PRAGMA foreign_keys = ON;       -- 外键约束（如需级联删除）
```

## 5. 数据访问模式

### 5.1 主查询（评论列表，仅已审核 + 置顶优先）
```sql
-- 置顶区按 pin_time 倒序（后置顶的排最上），普通区按时间倒序（最新在前），末尾 id 兜底防并列乱序
SELECT * FROM comments
WHERE page_id = ? AND site = ? AND is_audited = 1 AND parent_id = 0
ORDER BY is_pinned DESC, pin_time DESC, create_time DESC, id DESC
LIMIT ? OFFSET ?;

-- 某根评论的子回复（时间正序）
SELECT * FROM comments
WHERE root_id = ?
ORDER BY create_time ASC;
```

> 公开列表排序语义（`sort` 参数）：`asc`（默认）最新在前、`desc` 最旧在前、`hot` 点赞最多在前；置顶区固定按 `pin_time DESC`，与外部排序模式无关。

### 5.2 计数查询（仅已审核）
```sql
SELECT COUNT(*) FROM comments
WHERE page_id = ? AND site = ? AND is_audited = 1;
```

### 5.3 待审核列表
```sql
SELECT * FROM comments
WHERE is_audited = 0
ORDER BY create_time DESC
LIMIT ? OFFSET ?;
```

### 5.4 点赞原子更新（v2，并发安全；v3.1 去重窗口改为 1 分钟）
```sql
-- 1) 窗口内已有记录则刷新时间（视为一次新的有效点赞）
UPDATE likes SET create_time = ? WHERE comment_id = ? AND ip = ? AND create_time <= ?;
-- 2) 无记录时插入（UNIQUE(comment_id, ip) 兜底）
INSERT OR IGNORE INTO likes (comment_id, ip, create_time) VALUES (?, ?, ?);
-- 3) 上述任一步实际变更时才原子递增
UPDATE comments SET like_count = like_count + 1, update_time = ? WHERE id = ?;
```
> 点赞窗口 `LikeWindow = 1 分钟`：窗口内重复点赞幂等（不 +1），超过窗口再次点赞刷新记录并继续累加；`like_count` 永不重置。

### 5.5 评论提交（事务，待审）
```sql
INSERT INTO comments (page_id, site, nick, email, link, content,
                      parent_id, root_id, is_audited, is_pinned, ip, user_agent,
                      create_time, update_time)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, 0, 0, ?, ?, ?, ?);
```
> 站长回复（`ReplyComment`）额外写入 `is_admin=1, is_audited=1`（即时可见）；普通评论 `is_audited=0` 待审。

## 6. 数据迁移与升级策略

### 6.1 结构迁移
- 数据库内置 `migration_versions` 表追踪已执行版本（v2 决策 #15）
- 程序启动时比对版本号，逐级执行迁移 SQL（事务包裹，失败回滚）
- 迁移脚本存放于 `migration/` 目录：
  ```
  migration/
  ├── 001_init.sql              # 初始建表 + 索引（含早期 image_url，v3 由 003 移除）
  ├── 002_oauth_fields.sql      # 管理员表增加 github_openid / github_name / qq_name
  ├── 003_drop_image_url.sql    # v3 移除 image_url 字段
  ├── 004_add_email.sql         # 管理员表 email 字段 + 唯一部分索引 idx_admins_email
  ├── 005_add_is_admin.sql      # 评论表增加 is_admin 字段（站长回复标识）
  ├── 006_add_query_indexes.sql # 补充查询索引（idx_site_audited_time 等 4 个）
  ├── 007_add_twofa.sql         # 管理员表增加 twofa_enabled（邮箱验证码 2FA）
  ├── 008_add_admin_permissions.sql # 多管理员：can_delete / is_approved / is_owner（存量最早账号自动成为站长）
  ├── 009_add_admin_disabled.sql    # 管理员表增加 is_disabled（账号禁用）
  └── 010_add_pin_time.sql      # 评论表增加 pin_time（置顶时间排序）+ idx_page_site_pin
  ```
- 流程：启动 → 读 `migration_versions` 最大 version → 执行未应用的脚本 → 写入版本号

### 6.2 数据备份与恢复
- **备份**：`PRAGMA wal_checkpoint(TRUNCATE)` 后拷贝 `comment.db` 文件（详见《06-部署运维手册》）
- **恢复**：停机替换文件后重启服务即可
- 备份期间 WAL 模式保证业务无感知

## 7. 设计约束与约定

| 约定 | 说明 |
|------|------|
| 时间存储 | 一律 Unix 时间戳（秒），INTEGER 类型 |
| 删除策略 | 物理删除（含子回复级联），不做软删除（决策 #4） |
| 审核语义 | 前台查询强制 `is_audited = 1`；后台可见 0（待审）与 -1（垃圾） |
| 敏感词命中 | 自动 `is_audited = -1`，**进入后台「垃圾评论」列表**供管理员查看 |
| 隐私字段 | `email` / `ip` / `user_agent` 不出现在任何公开接口响应中 |
| 字符限制 | 昵称 1-20 字符、内容 1-500 字符、URL ≤ 200 字符 |
| 置顶上限 | 同一文章最多 3 条置顶（可配置 `comment.max_pinned_per_page`）；置顶区按 `pin_time` 倒序，取消置顶清空该值 |
| 点赞去重 | IP + `likes` 表 `UNIQUE(comment_id, ip)`，**1 分钟**窗口内同 IP 同评论仅 +1，计数永久累加 |
