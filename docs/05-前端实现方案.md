# dwxComment 前端实现方案 v3.1

> 版本：v3.1 ｜ 本文档为《02-系统架构设计》的前端细化
> 目标：原生 HTML + CSS + JavaScript，零构建、零框架，打包后 ≤ 25KB
> 基于《技术设计说明书 v2》拆分

---

## 1. 文件结构

```
front/
├── comment.html   # 评论区骨架（可内联至博客主题）
├── comment.css    # 样式，CSS 变量支持主题定制
├── comment.js     # 核心逻辑（ES5 兼容）
├── comment.min.js # esbuild 打包压缩产物（生产引用）
├── comment.min.css# 压缩样式产物
├── admin.html     # 管理后台单页（含 fontawesome 图标）
└── fontawesome/   # 图标资源
```

| 文件 | 职责 | 体积预估 |
|------|------|----------|
| comment.html | 渲染骨架：评论列表容器、表单、表情面板 | ~3KB |
| comment.css | 布局、卡片、响应式、暗黑模式变量 | ~8KB |
| comment.js | 数据请求、渲染、交互、存储、转义 | ~14KB |

## 2. 组件架构

```
dwxComment（单一入口，自动初始化）
├── 配置解析      data-* 属性 + 全局默认值
├── API 客户端    封装 fetch（GET/POST），统一错误处理
├── 状态管理      分页游标/页码、当前渲染评论、用户信息
├── 渲染器        createCommentNode() 递归渲染树（前端拼树）
├── 分页器        加载更多按钮 / 页码分页器（站点配置 pagerType 切换）
├── 表单模块      校验 / 防重 / 审核提示 Toast / 清空
├── 表情模块      Emoji 面板 + 快捷转义
├── 头像模块      候选头像按序加载（代理 > Cravatar > Gravatar > 字母）
├── 存储模块      localStorage 记住用户信息
├── 通知模块      「有回复时通知我」勾选
└── 主题模块      CSS 变量 + prefers-color-scheme
```

**初始化流程**：
```
DOMContentLoaded
  → 扫描 [data-dwx-comment] 容器（支持页面多个实例）
  → 解析配置（容器 data-* 优先级 > window.dwxComment 默认）
  → 渲染评论列表（首屏，仅 is_audited=1）
  → 绑定表单 / 加载更多 / 表情事件
```

## 3. 核心功能实现细节

### 3.1 评论列表渲染
- 默认排序：**置顶区按置顶时间倒序（后置顶的排最上）→ 普通区时间倒序（最新在前）**；可选最旧在前 / 按热度
- **树形拼装**：后端返回两层结构（`roots` + `children`），前端按 `parentId` / `rootId` 拼树（决策 #12），回复层级不限深度，默认展开 3 层，更深层级折叠显示
- **移动端扁平回复**：窄屏下回复直接平铺展示内容，不做深层嵌套折叠
- 回复头部显示 `@昵称` 提示（点击自动填充回复对象）
- **仅渲染 `is_audited=1` 的评论**（v2 变更）

### 3.2 XSS 防护
```js
// 所有用户内容一律走 textContent，绝不使用 innerHTML 插入用户数据
// 可选：内联 DOMPurify 轻量版做二次加固
function escapeHtml(str) {
  var div = document.createElement('div');
  div.textContent = str;
  return div.innerHTML;
}
```
- 渲染规则：`nick` / `content` / `link` 全部转义
- Markdown 图片语法 `![](url)` 渲染时先转义再正则替换，杜绝注入
- 禁止渲染 `<script>`、`<iframe>` 等标签

### 3.3 表情支持
- 内置表情面板（常用 Emoji 数组），点击插入光标处
- 快捷转义表：
  ```
  :) → 😊   :( → 😞   :D → 😄   :P → 😛
  :heart: → ❤️   :thumbsup: → 👍
  ```
- 提交时保留 Emoji 原文（Unicode 存储），不转换图片

### 3.4 头像展示
- 有邮箱：后端返回**有序候选数组 `avatarUrls`**，按序加载，任一候选**超时（3 秒）自动跳过**到下一候选：
  1. QQ 邮箱 → 本服务代理 `/api/v1/avatars/{id}`（服务端代拉，脱敏不暴露 QQ 号）
  2. `https://cravatar.cn/avatar/{md5}?d=404&s=48`
  3. `https://www.gravatar.com/avatar/{md5}?d=404&s=48`
- 无邮箱或全部候选失败：基于昵称哈希生成几何头像（SVG，随机颜色+图形）/ 字母头像
- 站长头像优先展示站点配置的 `adminAvatar`

### 3.5 用户身份记忆
```js
// 首次评论成功后写入
localStorage.setItem('lc_user', JSON.stringify({ nick, email, link }));
// 下次加载时自动填充表单，提供「清除信息」入口
```

### 3.6 评论提交交互（v2 变更）
- **实时校验**：昵称必填、内容非空，失焦即时提示
- **防重复**：提交后按钮置灰 + 3 秒倒计时
- **[v2 移除]** 乐观更新直接插入列表
- **[v2 替换为]** 提交成功后显示 Toast 提示「评论已提交，审核通过后显示」
- 邮箱输入框旁复选框：「有回复时通知我」（未填邮箱时勾选无效，提示先填邮箱）

### 3.7 分页加载
- 分页方式由**站点配置 `pagerType`** 决定（后台下发，前端自动切换）：
  - `more`（默认）：**加载更多按钮**，显示剩余条数（如「加载更多（剩余 12 条）」），点击追加下一页
  - `pages`：**页码分页器**——窗口化页码（当前页 ±2，首尾固定 + 省略号收拢，任意总页数不溢出）、上一页 / 下一页、「第 x/y 页」信息、跳至指定页、每页条数选择（10/20/50/100，容器自定义 `data-page-size` 自动补充）
- 加载中显示 loading 状态，防止重复触发
- 页码模式下每次切页替换列表；加载更多模式仅首页清空列表，跨页保留已加载评论与折叠展开标记

### 3.8 回复通知勾选
- 邮箱输入框旁复选框：「有回复时通知我」
- **全局开关**：`settings.notify_reply` 关闭时前端隐藏勾选框；开启时默认勾选，用户可取消
- 提交时若勾选，将 `notify=true` 随请求发送
- 未填邮箱时勾选无效（提示先填邮箱）

### 3.9 暗黑模式
```css
:root {
  --lc-bg: #ffffff;
  --lc-text: #1f2328;
  --lc-border: #d0d7de;
  --lc-accent: #0969da;
}
@media (prefers-color-scheme: dark) {
  :root {
    --lc-bg: #0d1117;
    --lc-text: #e6edf3;
    --lc-border: #30363d;
    --lc-accent: #58a6ff;
  }
}
```
- 支持手动切换（`data-theme="dark"` 覆盖系统偏好）
- 所有颜色必须走 CSS 变量，禁止硬编码

## 4. 嵌入方式

### 4.1 标准嵌入（推荐）
```html
<div id="dwx-comment"
     data-page-id="/post/hello.html"
     data-server="https://api.example.com"
     data-site="default"
     data-locale="zh-CN">
</div>
<script src="/comment/comment.js" defer></script>
<link rel="stylesheet" href="/comment/comment.css">
```
> `data-locale` 预留为国际化扩展，一期仅支持中文。

### 4.2 全局配置（可选）
```html
<script>
  window.dwxComment = {
    server: 'https://api.example.com',
    site: 'default',
    locale: 'zh-CN',
    pageSize: 10,
    sort: 'asc',          // asc=最新在前（默认）| desc=最旧在前 | hot=按热度
    maxDepth: 3,
    emojiPanel: true,
    darkMode: 'auto',     // auto | light | dark
    maxLength: 500        // 评论字数上限，服务端配置接口下发后覆盖
  };
</script>
```
> 优先级：容器 `data-*` 属性 > `window.dwxComment` > 内置默认值
> 排序切换器在评论区顶部（最新 / 最旧 / 热度），用户选择会覆盖默认 `sort`

### 4.3 多实例
- 同一页面可挂载多个评论组件（不同 `data-page-id`）
- 各实例独立状态、独立请求，互不干扰

## 5. 事件与生命周期

| 事件 | 触发时机 | 用途 |
|------|----------|------|
| `lc:ready` | 组件初始化完成 | 外部扩展钩子 |
| `lc:loaded` | 评论列表加载完成 | 统计/埋点 |
| `lc:submitted` | 评论提交成功（待审） | 通知宿主页面刷新计数 |
| `lc:error` | 请求失败 | 统一错误提示 |

**监听方式**：
```js
document.getElementById('dwx-comment')
  .addEventListener('lc:submitted', function (e) {
    console.log('评论已提交待审', e.detail);
  });
```

## 6. 浏览器兼容性

| 特性 | 要求 | 兼容策略 |
|------|------|----------|
| 语法 | ES5 | 不使用箭头函数/let/const/模板字符串 |
| API | XMLHttpRequest 或 fetch | 提供 fetch polyfill（内联 <1KB） |
| 样式 | CSS 变量 | 不支持时回退为浅色默认值 |
| 分页 | 无特殊 API | 加载更多 / 页码分页均基于普通按钮与事件委托，不依赖 IntersectionObserver |

---

## 7. 性能约束
- 首屏 JS+CSS+HTML 合计 ≤ 25KB（gzip 后 ≤ 8KB）
- 评论列表渲染：1000 条数据内无卡顿
- 静态资源由 Nginx 托管并强缓存（`expires 7d`）
- **构建工具**：采用 [esbuild](https://esbuild.github.io/) 打包压缩（开发时 `esbuild comment.js --bundle --minify --outfile=comment.min.js`），需 Node.js 环境
