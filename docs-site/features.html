Features

围绕「零门槛发表、全量审核、发后不改」三大理念展开的功能矩阵。

01

核心评论功能（P0）

发表评论

昵称（必填）、内容（必填）、邮箱 / 网站（选填）。支持 Markdown 图片语法 ![](url) 与裸图片 URL 自动渲染。提交后 is_audited=0 待审入库。

回复评论

对任意层级评论回复，@昵称 提示，点击自动填充回复对象。回复层级不限深度，前端默认展开 3 层，更深层级折叠显示。

列表分页（两层结构）

根评论分页 + 子评论全量返回，前端按 parentId / rootId 拼装为树。根评论排序：置顶优先 → 时间正序；默认 10 条/页，公开最大 50、管理最大 100。

评论计数 + 点赞

按页面统计已审核评论总数；点赞基于 IP + likes 表 24h 去重、原子递增，不提供取消赞。

02

交互增强功能（P1）

Emoji 表情面板

内置 80+ 常用 Emoji 面板，点击插入光标处；:) 等快捷转义。

用户信息记忆

昵称 / 邮箱 / 网站存 localStorage，下次自动填充，可一键清除。

回复邮件通知

默认勾选「有回复时通知我」，未填邮箱时提示先填邮箱；全局开关可在后台配置。

头像体系

前端不暴露邮箱；有邮箱时后端返回真实头像候选（QQ 代理 > Cravatar > Gravatar），全部失败生成字母头像；无邮箱时按昵称哈希生成字母 + 颜色。

Markdown 图片渲染

不做完整 Markdown；仅支持 ![](url) 语法与带图片扩展名的裸 URL，先转义再渲染，杜绝注入。

暗黑模式

CSS 变量 + prefers-color-scheme 自动适配，支持 data-theme 手动覆盖。

03

管理功能

功能说明
管理员登录用户名 + 密码，JWT 有效期 24h；首个注册用户自动成为管理员且仅允许一个；支持 QQ / GitHub / 邮箱验证码登录与两步验证（TOTP）
评论审核通过 / 标记垃圾；通过时清除对应文章缓存；待审列表仅提供「通过」，标记垃圾走单独操作
批量操作批量审核通过 / 批量删除
全量评论列表按状态 + 站点筛选 + 关键词搜索（昵称 / 内容 / 邮箱）
评论删除物理删除（含子回复级联），不做软删除
评论置顶仅已审核评论可置顶；每文章最多 3 条（可配置）
站长回复管理员以站长身份回复任意评论，is_admin=1 前台展示可自定义的「站长」徽章，直接已审核即时可见，自动触发被回复者邮件通知
站点配置settings 表 key-value 存储：站点名、SMTP、通知开关、站长昵称 / 徽章 / 头像、每页条数、置顶上限等
账号管理站长审批新账号、授予删除权限、禁用 / 删除账号
数据迁移导入 Waline / Twikoo / Disqus JSON；按站点与时间范围全量导出；一键备份（WAL checkpoint + 文件下载）
04

反垃圾与审核

全量人工审核

所有评论提交后 is_audited=0 待审，管理员通过后才对公众展示。统一策略，不可回退。

本地敏感词库

内嵌百级基础词库（可替换），命中自动标记 is_audited=-1（垃圾），仍显示在待审列表中供管理员查看。

频率限制

仅针对评论提交接口：单 IP 每秒 ≤ 5 次、每日 ≤ 20 条评论；登录接口单 IP 每分钟 ≤ 5 次。

重复内容拦截

5 分钟内、同一 pageId、单 IP 连续相同内容拦截；链接限制可配置，默认不限制。

05

06

运维与多站点

健康检查

/api/v1/health 返回状态与版本，供 systemd 与负载均衡探测。

数据库自动迁移

基于 migration_versions 表版本号逐级迁移，事务包裹，失败回滚。

多站点隔离

请求参数 site 区分（防伪造），未传默认 default，缓存与配置均按站点隔离。
