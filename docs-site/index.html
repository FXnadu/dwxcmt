CORE IDEAS

核心理念

极致轻量

拒绝冗余中间件与重型框架。Go 单二进制 + SQLite 单文件 + 原生 JS，无 Node.js、无 Redis、无消息队列。

数据完全自主

评论数据存放在自己的服务器本地文件，可随时导出、备份、迁移，不依赖任何第三方平台。

零用户门槛

评论者无需注册、无需登录，填昵称即可发言；管理员与访客走完全不同的通道。

安全优先

全量人工审核 + 本地敏感词 + 双层限流 + 参数化查询，防注入、防 XSS、防刷屏。

一句话定位 替代 Twikoo、Waline 等轻量评论服务的自托管方案 —— 在不牺牲核心体验的前提下，实现最低资源开销与最简单部署，尤其适合对性能与自主可控有极致要求的技术博客。
