Design

「宁可功能收敛，不做过度设计」—— 每一项功能、每一个决策，都围绕极致轻量与数据自主展开。

01

核心理念

零用户门槛

评论者无需注册、无需登录，填昵称即可发言。访客与管理员走完全不同的通道，产品复杂度因此大幅收敛。

全量审核

所有评论默认待审核，管理员通过后才对公众可见。审核策略统一、不可回退，这是内容安全的第一道也是最后一道防线。

发后不改

评论提交后用户不可编辑、不可删除，误发联系管理员处理。砍掉编辑 / 删除能力，换来的是系统与治理的简单。

极致轻量

宁可功能收敛，不做过度设计。任何「加分项」如果带来运行时或心智负担，都优先拒绝。

02

设计原则

原则落地方式
零重型依赖拒绝 Redis、消息队列、Node.js 运行时、独立数据库；内存缓存自研 LRU，异步任务用协程 + channel
数据自主数据存本地 SQLite 单文件，提供导入（Waline / Twikoo / Disqus）导出与一键备份，随时可迁走
安全内建全量人工审核兜底、参数化查询防注入、转义渲染防 XSS、JWT Header 鉴权免疫 CSRF、双层限流防滥用
编译即交付纯 Go 零 CGO 交叉编译，复制一个二进制加一个配置文件即可上线
简单优于强大明确「不做清单」，把省下的复杂度投入核心体验的打磨
