Visual

设计语言：低饱和紫灰、几何小圆角、玻璃态表面、轻量字体 —— 与「极致轻量」的产品理念一脉相承。

01

设计语言

低饱和紫灰

主色取自紫灰中性调（ice #70687a / violet #6e627a），沉静不抢眼，长时间阅读舒适。

几何小圆角

统一 2px 圆角，克制而利落；按钮、卡片、输入框、徽章保持同一半径，形成一致的几何语言。

玻璃态表面

半透明白色表面 + backdrop-filter 毛玻璃，层次细腻、轻盈通透；暗黑模式中透明度进一步降低。

轻量字体

正文 Inter 300 字重 + 标题 Space Grotesk，正文 14px、行高 1.7，克制留白，聚焦内容。

03

字体与排印

标题字体 Space Grotesk

Aa 标题文字

英文展示型字体，几何感强，用于标题与数字；字重 300~500，字间距 -0.02em。

正文字体 Inter

Aa 正文内容文字

正文 14px / 行高 1.7 / 字重 300，中文回退 PingFang SC、Microsoft YaHei。

04

圆角、阴影与间距

圆角

--radius: 2px，几何小圆角贯穿所有组件；标签采用 999px 胶囊圆角作为唯一例外。

阴影

双层柔和阴影：0 1px 2px rgba(36,38,43,.04), 0 2px 8px rgba(36,38,43,.06)，暗色下加深。

间距

卡片内边距 1.5rem，网格间距 16px，页面顶部 40px + 底部 80px，留白克制。

05

组件规范

按钮

已通过 待审核 垃圾 站长

inline-flex 居中、gap 0.45em；hover 提亮背景 + 文字转 ice 色；禁用态透明度 0.5。状态徽章使用低饱和底色 + 深色文字 + 同色边框。

表单

输入框全宽、内边距 0.75rem 1rem、2px 圆角、surface 底；focus 时边框变 border-hover、背景提亮为 surface-strong。textarea 允许垂直拉伸，占位符使用 muted 色。

评论卡片

评论头：字母头像（昵称哈希 + 随机色）或真实头像 → 昵称 → 站长徽章 → 时间 → 操作；内容区先转义后渲染，图片懒加载；根评论置顶优先排序。

图标

统一 inline-flex + 定高 1em 居中，垂直对齐 middle，与文字基线对齐；按钮内图标 0.95em。

06

设计令牌（CSS 变量）

/* 浅色 / 暗色双主题同源设计令牌 */
:root {
  --bg: #ffffff;                  /* 页面背景 */
  --surface: rgba(255,255,255,.65); /* 卡片表面（玻璃态） */
  --surface-strong: rgba(255,255,255,.85);
  --text: #24262b;                /* 主文字 */
  --muted: rgba(36,38,43,.62);    /* 次要文字 */
  --border: rgba(36,38,43,.1);    /* 边框 */
  --border-hover: rgba(36,38,43,.22);
  --ice: #70687a;                 /* 品牌冰灰 */
  --violet: #6e627a;              /* 品牌紫罗兰 */
  --radius: 2px;                  /* 几何小圆角 */
  --shadow: 0 1px 2px rgba(36,38,43,.04), 0 2px 8px rgba(36,38,43,.06);
  --font-display: "Space Grotesk", "Inter", sans-serif;
  --font-body: "Inter", -apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif;
}
自定义主题 用户只需覆盖 .lc-wrap 内的变量即可定制评论组件外观；所有组件颜色均走变量，禁止硬编码。
